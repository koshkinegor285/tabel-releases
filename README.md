# Табель / Tabel

**Табель** — личное приложение для Android для учёта отработанных смен: таблица недели, сотрудники, расчёт по дневной ставке и выплаты. Данные хранятся на телефоне, копия ведётся в Google Таблице на Google Диске владельца, а при удалении приложения данные можно восстановить из этой таблицы.

**Tabel** is a personal Android app for tracking employees' work shifts: a weekly timesheet, staff, pay calculation by day rate and payments. Data is stored on the phone, with a backup copy kept in a Google Sheet in the owner's own Google Drive that can be used to restore the data if the app is removed.

## Установка и обновление / Install and update

APK-файлы лежат в разделе [Releases](https://github.com/koshkinegor285/tabel-releases/releases). Приложение само проверяет новые версии в этом репозитории и ставит их поверх установленной (подпись и контрольная сумма проверяются).

APK files are published under [Releases](https://github.com/koshkinegor285/tabel-releases/releases). The app checks this repository for new versions and installs them over the installed one (signature and checksum are verified).
